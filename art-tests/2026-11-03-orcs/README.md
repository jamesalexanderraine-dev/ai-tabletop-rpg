# Orcs (Art Style Proofs, Round 15)

Six orc scenes, two takes each on `gemini-3-pro-image`, built from the orc sheets added to `src/art/visual-bible.json` from the Orcs and Orc Badlands pages (`scenes.json`; full prompts in `log.json`). Orc bodies and skin are a Claude Code proposal.

- Every take reads warm and homemade rather than Sauron; the armour-maker is the same orc in both takes.
- Skin colour drifted (grey-green, bright green, red) and a few humans crept into crowds; the orc sheet was tightened afterwards, so `log.json` predates that fix.
- Border trimmed on village 1.
